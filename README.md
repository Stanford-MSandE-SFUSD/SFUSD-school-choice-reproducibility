# Reproducibility Materials for *Designing School Choice for Diversity in the San Francisco Unified School District*

This repository provides reproducibility materials for:

> I. Lo, K. Mentzer, M. YahyazadehJeloudar, H. O'Connell, J. Monardo, and I. Ashlagi. *Designing School Choice for Diversity in the San Francisco Unified School District*. Proceedings of the National Academy of Sciences, accepted July 2026.

The computational materials are organized across two public repositories:

* **[Student assignment code](https://github.com/Stanford-MSandE-SFUSD/student-assignment-public)**
  Simulation tools for the SFUSD student-assignment system, including Deferred Acceptance and policy variants, zone inputs, and evaluation of assignment outcomes.

* **[Choice model code](https://github.com/Stanford-MSandE-SFUSD/SFUSD-Choice-public)**
  Code for estimating choice models and generating the preference estimates used in the assignment simulations and evaluation.

The two repositories contain documentation describing their setup, data requirements, and analysis pipelines.

## Data availability

The analyses in the paper use SFUSD student-level data covered by data use agreements. These confidential data are not included in the public repositories.

The public repositories include synthetic or otherwise non-confidential data and documentation sufficient to inspect and run the public reproducibility pipeline. See the individual repositories for details on which analyses require confidential SFUSD data.
